⚙️ 设置

📱 安装到手机桌面

想让本页像 App 一样出现在手机桌面？需要先部署到网上：

  1. 注册 GitHub 账号 (github.com)
  2. 创建新仓库（如 my-tracker）
  3. 上传这 3 个文件到仓库
  4. Settings → Pages → 选 main 分支 → Save
  5. 等 1 分钟后访问 https://你的用户名.github.io/my-tracker/
  6. Chrome 浏览器打开该地址 → 菜单 → "添加到主屏幕"

（部署后图标、离线功能、全屏运行全部自动生效）
